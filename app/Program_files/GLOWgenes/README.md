# GLOWgenes rankings of PanelApp panels

`glowgenes_panelapp_ranks.tsv.gz` (Supplementary Table 2: GLOWgenes rank of each gene, rows, for each
PanelApp panel, columns; rank 0 = genes of the panel) and `glowgenes_panelapp_panels.tsv.gz`
(Supplementary Table 1: disease class of each panel), unmodified, from:

Benítez Y, Uría-Regojo G, Mínguez P. A global survey of systems biology-based predictions of
gene-rare disease associations to enhance new diagnoses. Sci Rep 2026. doi:10.1038/s41598-026-54510-3
